# QuickChart Demo

Live visual demonstration of the QuickChart Laravel Package.

## View Demo

Open `index.html` in your browser or visit:
**[GitHub Pages Demo](https://giobi.github.io/quickchart/demo/)** (once deployed)

## Features Demonstrated

- All chart types (bar, line, pie, doughnut, radar)
- Custom colors and styling
- Size variations
- Laravel Controller integration
- Blade template examples
- Color palette reference
- Method documentation
- Performance metrics

## Local Development

```bash
# Clone repo
git clone https://github.com/giobi/quickchart.git
cd quickchart/demo

# Open in browser
open index.html
# or
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Live Examples

All charts shown are **live** - they're generated in real-time by the QuickChart Worker at https://quickchart.giobi.workers.dev

Try modifying the URLs in the HTML to see different charts!
